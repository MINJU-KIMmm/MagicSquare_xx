## 1. Executive Summary

4×4 부분 마방진(빈칸 2개) OO 과제를 **손으로** 푸는 학습자는, 행 4개 합만 맞으면 검산을 끝내는 습관 때문에 **대각선 검산 누락**으로 약 **20분**을 낭비한다.  
본 프로젝트는 솔루션(앱·UI·Solver) 선행 없이, **행·열·대각선 10줄 합=34** 판정 기준을 먼저 고정하여 “행만 맞으면 끝” 판정을 제거하는 것을 1차 목표로 한다.

## 3. 도메인 정의 (Magic Square)

| 항목 | 정의 |
|------|------|
| 격자 | 4×4 |
| 숫자 | 1~16, 각 1회 |
| 목표 합 | **34** (행·열·대각선 동일) |
| 검산 대상 | **10줄** — 행 4 + 열 4 + 주대각선 1 + 반대각선 1 |
| 과제 형태 | **빈칸 2개** 위치 찾기 및 채우기 |
| 설계 맥락 (후속) | ECB — `MagicSquare`, `SquareValidator`, `Solver` 등 |

## 4. Mom Test — 과거 사실 (증거)

### 4.1 인터뷰 답변

| # | 과거 사실 |
|---|-----------|
| 1 | 지난주 OO 과제에서 빈칸 2개를 넣고 행·열·대각선 합을 맞춰야 했음 |
| 2 | 대각선 하나를 검산에서 빠뜨려 **약 20분** 소요 |
| 3 | 그 20분 동안 **다시 더하기**만 수행 |
| 4 | 행·열 합은 **맞다고 확신**한 상태였음 |
| 5 | 대각선을 다시 본 계기: **과제 조건 다시 보기** |
| 6 | 대각선 요구는 알고 있었으나 **검산 순서**에서 빠뜨림 |
| 7 | 평소 검산 순서: **1행 → 2행 → 3행 → 4행 → 끝** |
| 8 | 그 전에 “4행까지 맞고 끝” 후 열/대각선 때문에 틀린 적은 **없음** |
| 9 | 대각선 맞춘 뒤 **제출**함 |

### 4.2 Mom Test 증거 3줄 (직접 인용)

1. “지난주 OO 과제에서 빈칸 2개 넣고 행·열·대각선 합 맞췄는데 **대각선 하나를 빼먹어서 20분 날렸다**”
2. “**1행 → 2행**” … “**3, 4행**” → “**끝**”
3. “행·열은 **확신한 상태**” / “**과제 조건 다시보기**”

## 5. 문제 정의

### 5.1 표면 문제 (잘못된 정의 — 하지 않을 것)

- “4×4 마방진 **검증 프로그램**을 만든다”
- “ECB로 **SquareValidator**를 만든다” (문제 정의로서)
- “대각선을 **자동으로 체크하는 앱**을 만든다”
- **행만** 검증하는 Validator
- Solver / MissingFinder / UI 선행

### 5.2 진짜 문제 (한 문장)

> 손으로 4×4 부분 마방진(빈칸 2개, 목표 합 34)을 풀 때 **행 4개 합만 맞으면 끝났다고 판정**하고, **10줄(행 4·열 4·대각선 2) 검산**을 과제 조건을 다시 보기 전까지 수행하지 않아 **틀렸을 때 같은 덧셈을 반복**하며 **약 20분**을 쓴다.

**포함 요소**

| 유형 | 내용 |
|------|------|
| 불편 | 같은 덧셈 반복 |
| 비용 | 약 20분 |
| 판정 | 행 4개 = 끝 |
| 재현 | 1행 → 2행 → 3·4행 → 끝 |

## 6. 문제 → 해결 방향 (솔루션 최소화)

| Mom Test 문제 | 1차 대응 (Session 3) |
|---------------|----------------------|
| 행-only 판정 | **10줄 합=34** Rule 고정 |
| 대각선 누락 | 대각선 2개 필수 검증 + 실패 테스트 |
| “확신한 상태” | Rule ↔ Test 1:1 체크리스트 |
| 과제 조건 재확인 의존 | Rule 문서에 10줄 명시 |

**주제 한 문장 (Session 3)**  
4×4 마방진에서 “행만 맞으면 끝”이라는 판정을 막기 위해, **행·열·대각선 10개 합이 34인지** 빠짐없이 판정하는 기준을 먼저 고정한다.

## 11. 결론

MagicSquare_1004의 문제는 “마방진 앱 부재”가 아니라 **10줄(합 34) 검산 판정의 체계적 누락**이다.
