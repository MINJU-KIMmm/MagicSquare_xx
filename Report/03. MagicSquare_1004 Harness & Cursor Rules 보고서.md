## 4. `.cursorrules` 초안 요약

| 영역 | 핵심 규칙 |
|------|-----------|
| **도메인** | 4×4, 빈칸 2개, 1~16, `MagicConstant` SSOT(34), 출력 `int[6]` 1-index |
| **오류** | E001~E007 → boundary; **entity는 E001~E005 처리 금지** |
| **ECB** | `boundary → control → entity`, entity의 `*` import 금지 |
| **Dual-Track** | Logic(`D-*`, entity/control) Domain Mock 금지 / UI(`U-*`, boundary) Mock 허용 |
| **테스트 명명** | `test_d_*` / `test_u_*`, ID `D-*` / `U-*` |
| **TDD** | RED→GREEN→REFACTOR, assert 완화·skip·xfail 금지 |
| **AI** | 한국어, Phase/Layer/Track 선언, commit은 사용자 요청 시만 |
