**Phase:** `green | Layer: entity | Track: Logic`

### 3.1 RED 재확인

```bash
python -m pytest tests/entity/test_d_loc_01.py::test_d_loc_01_blank_coords_row_major -v
# → FAILED: RED: D-LOC-01 — 구현 없음, 의도적 실패
```

### 3.2 최소 구현

| 파일 | 내용 |
|------|------|
| `src/entity/blank_coords.py` | `find_blank_coords(grid)` — row-major, 1-index, `BLANK_CELL`/`GRID_SIZE` |
| `tests/entity/test_d_loc_01.py` | `pytest.fail` 제거 → `assert result == [(2, 2), (3, 3)]` |

**알고리즘:** `GRID_SIZE` 이중 루프, `grid[r][c] == BLANK_CELL` → `(r+1, c+1)` 수집.

### 3.3 pytest (PASS)

```bash
python -m pytest tests/entity/test_d_loc_01.py::test_d_loc_01_blank_coords_row_major -v  # 1 passed
python -m pytest tests/entity/test_d_loc_01.py -v                                           # 1 passed
```

### 3.4 REPL 스모크

```text

```
